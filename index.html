      Mode d'emploi

      • Clique sur la carte pour poser le départ, puis les points suivants : le tracé suit les sentiers et les étapes se recalculent à chaque clic.
      • Glisse un point blanc pour déplacer le tracé.
      • « Ligne droite » sert pour les passages hors sentier.
      • Survole le profil pour voir où tu es sur la carte.
      • L'export GPX contient une trace par étape et un point à chaque fin d'étape.
